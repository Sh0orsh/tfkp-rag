# Отчёт: доказательный RAG по ТФКП

## Архитектура

Источник — выданный корпус лекций Горяйнова и Половинкина (2025). Исходные `block_id` сохраняются. Блоки разбиваются на чанки по 240 слов с перекрытием 40 слов. BM25 и `intfloat/multilingual-e5-small` формируют ранжирование; итоговая система объединяет списки с reciprocal rank fusion (константа 60) и передаёт 12 уникальных блоков в Qwen3.5-4B. Генерация локальная на GPU Kaggle в 4-битном режиме; embeddings вычисляются на CPU. Отказ предусмотрен, когда сведений недостаточно или не получен корректный структурированный ответ.

## Эксперименты (исторический прогон, 15 dev-вопросов)

| Режим | Точность вариантов | Средняя стоимость C | Медианная задержка, мс |
|---|---:|---:|---:|
| no_context | 46.67% | 1521.4 | 21902 |
| single_search | 73.33% | 6913.33 | 29484 |
| final | 60.00% | 6747.67 | 32381 |
| ablation_no_dense | 73.33% | 6913.33 | 29784 |
| ablation_no_bm25 | 60.00% | 5284.87 | 29909 |

Baseline BM25 и отключение dense дают 73,33%; гибридная система и отключение BM25 — 60%. На 15 вопросах добавление dense не помогло; нельзя делать общий вывод о качестве методов. Исторические показатели не пересчитывались после правок инфраструктуры.

`Q` не указан: предоставленный `dev_gold.jsonl` не содержит категорий, а эталонные ссылки помечены как эвристические. Скрипт `evaluate_existing.py` рассчитывает `Q`, только если имеются все четыре категории; в эксперименте без контекста `Q` всегда пустой.

## Три ошибки итоговой системы

- **q_002**: эталон ['A', 'C'], ответ [], отказ=True. Первые найденные блоки: ['b_011_001', 'b_011_002', 'b_016_001', 'b_078_003', 'b_012_001']. Причина по журналу: ошибка разбора JSON (`No JSON`), из-за чего система отказала.
- **q_005**: эталон ['A', 'B'], ответ ['B', 'C', 'D'], отказ=False. Первые найденные блоки: ['b_030_002', 'b_066_002', 'b_042_002', 'b_031_001', 'b_026_001']. Причина по журналу: неверный выбор вариантов при успешном ответе; требуется анализ контекста для разграничения поиска и генерации.
- **q_009**: эталон ['A', 'C'], ответ ['A'], отказ=False. Первые найденные блоки: ['b_013_001', 'b_012_001', 'b_119_001', 'b_011_002', 'b_120_001']. Причина по журналу: неверный выбор вариантов при успешном ответе; требуется анализ контекста для разграничения поиска и генерации.

## Ресурсы и ограничения

GPU: Kaggle GPU (точная модель не зафиксирована). Время сборки, пиковая RAM и размер индекса в имеющихся результатах не сохранены — необходимо измерить перед сдачей. Код локального режима **не удовлетворяет** требованию официального OpenAI-совместимого endpoint, заданному в инструкции; отдельный API-режим сознательно не включён по запросу автора.
